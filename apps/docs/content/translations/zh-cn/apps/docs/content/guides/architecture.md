# 架构

项目分为 Engine、Core、框架适配器与 UI 集成。把行为放在其拥有的层次，避免将 React 生命周期混入共享引擎。

## 四个层次

| 层次        | 职责                                                                 |
| ----------- | -------------------------------------------------------------------- |
| Engine      | Markdown/LaTeX 处理、MDAST/HAST、增量算法、定义 registry、平滑控制器 |
| Core        | 会话、块规划、贡献编排、聚合脚注、共享协调与尾部信号                 |
| React / Vue | 树转换、框架上下文或插槽、挂载/提交与卸载、SSR、水合和光标测量       |
| Mantine     | React 主题排版、代码显示、JSON 与 Mermaid                            |

## 一帧数据流

应用提供完整 source，先进行 BOM/LaTeX 与额外预处理。引擎解析、转换并清洗 HTML，协调路径可能使用经过验证的虚拟定义/占位符。宿主执行最终 URL 策略并转成框架元素。

React 通过块规划与缓存复用部分元素；Vue 转换整帧树并让框架更新。共享引擎不代表两者使用同一个元素缓存。

## 提交边界

渲染准备不写入共享贡献。宿主在 commit/mount 后注册与发布，卸载配对释放和退订。跨片段定义随已提交状态更新，服务器只使用本地定义。

会话树是借用结果，渲染阶段要修改时克隆。增量失败重试完整解析，仅 typed HTML 深度错误降级为纯文本；其他异常传播。

模块地图与处理阶段细节见[英文架构文档](english:docs/guides/architecture/)。
