# 历史基准：2026 年 7 月

本页是历史测量入口，记录 1.x 时期块复用与增量前缀解析的浏览器对照。它区分引擎阶段耗时和 React commit，并记录输入规模、重复次数与噪声范围。

## 如何解读

历史结果受当时版本、设备、开发构建、输入投递与样本选择限制，不能作为当前版本或 Vue 的速度承诺。不同阶段的节省不应相加成未经测量的整体收益。

原始数据表、负载和复现记录完整保留在[英文历史档案](english:docs/guides/benchmark/)，避免在翻译中改写测量证据。

测量当前改动请使用[基准测试方法](benchmarking.md)，记录新的版本与环境，并保留正确性验证。
