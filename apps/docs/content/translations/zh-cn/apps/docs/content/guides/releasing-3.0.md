# 3.0 发布接受记录

这是原始 3.0.0 晋升的历史记录，不描述今天 npm channel 的状态。当前操作请阅读[发布流程](releasing.md)。

## 当时的发布范围

Engine、Core、React、Vue 和 Mantine 同步发布为 3.0.0，独立高亮插件为 1.0.2。稳定晋升相对 RC 的变化是版本元数据、peer 范围与文档，没有新的运行时源代码变化。

## 如何使用历史证据

RC 的接受条件、审核例外、workflow 链接和实际验证证据保留在[英文完整记录](english:docs/guides/releasing-3.0/)。它们只适用于当时已经完成的候选，不授权将来的发布跳过审核。

已经存在的标签与 npm 版本不能重新发布。检查旧产物时还要确认其预期 channel 是否已被新版本推进；因此历史标签验证不一定能通过当前 channel 校验。
