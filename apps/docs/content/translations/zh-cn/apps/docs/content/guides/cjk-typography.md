# CJK 排版

CJK 支持包括解析边界、字符间距和字体呈现三个不同层次，不能只通过换字体解决所有问题。

## 语法与可选变换

引擎处理 CJK 文字附近的强调/删除线分隔符。pangu 插件负责 CJK 与半角字符间距，smartypants 提供排版标点及 CJK 引号处理；它们属于默认可选目录，可以通过重新选择 enginePlugins 关闭。

源文本中的段内换行默认变为硬换行。不要假定行为与把软换行折叠为空格的渲染器完全相同。

## 字体与样式

字体由应用与框架样式负责。选择包含所需字形的字体回退，检查中英文、数字、代码与数学混排。React 使用其 typography/变量系统，Vue 使用基础 CSS 与自己的 class/style；Mantine 跟随 UI 主题。

预处理器处理文本，插件处理语法/变换，CSS 处理视觉，分别在相应层配置。更多字体变量与关闭示例见[英文 CJK 指南](english:docs/guides/cjk-typography/)。
