# React CSS 设计变量

内置排版通过 CSS 自定义属性暴露颜色、间距、边框与字号等设计参数。先导入需要的 typography CSS，再在适当作用域覆盖变量。

## 字号基准

fontSize 属性设置根字号，默认 0.9375rem。--aim-font-size-root 给内部基于根字号的尺寸提供稳定参照，避免嵌套 em 不断叠乘。只有按该字号定义的尺寸会随它变化；固定 px 等值不会自动缩放。

## 作用域与主题

在消息容器或自己的 Typography 上覆盖所需变量，避免全站规则影响无关组件。自定义 Typography 必须合并注入的 style，才能保留根字号变量。

浅色和深色模式需要分别检查文字、代码、引用和边框对比度。变量名称是公开契约，默认值可在兼容版本内调整；依赖精确视觉效果时显式固定自己的值。

## 完整变量表

变量种类较多，查阅[英文完整变量表](english:docs/guides/design-tokens/)获取各名称和缺省值。React 变量不是 Vue 基础样式或 Mantine 主题的替代接口；对应框架按自身样式系统定制。
