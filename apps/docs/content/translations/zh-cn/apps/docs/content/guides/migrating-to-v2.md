# 从 1.x 迁移到 2.x

这是历史迁移指南。直接升级到当前版本时，还需要阅读之后的发布记录与[包命名迁移](framework-transition.md)。

## 配置从对象变为平铺属性

2.0 移除 1.x 的对象 config 通道及集成默认通道，改用公开平铺属性。把对应主题、行为和管线选项移到组件属性，并核对新名称与默认值，不能直接把整个旧对象展开后假定等价。

## 插件与 Hooks

引擎插件改为封闭目录，使用包导出的对象选择启用项；数组替换集合，不追加任意 remark 插件。五个窄上下文 Hooks 让使用者只读取所需系统，聚合 Hook 仍用于需要完整状态的组件。

## 集成库

包装器用自己的平铺属性与扩展组，内层同名组整体覆盖外层。保持元数据泛型与 peer 范围，检查公开导出和 CSS 路径。

最初的兼容目标不表示以后所有 2.x 版本都产生相同 HTML。应用应验证语义、链接与脚注，而非依赖生成 ID 的具体字节。

完整 old → new 字段映射与前后代码见[英文历史迁移指南](english:docs/guides/migrating-to-v2/)。
