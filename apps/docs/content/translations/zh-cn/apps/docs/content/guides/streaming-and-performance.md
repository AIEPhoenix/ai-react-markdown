# React 流式渲染与性能

React 使用共享解析会话和块规划，并缓存可复用的元素。Vue 不采用相同的 React 块缓存路径。

## 开关之间的关系

blockMemo 默认 true，启用块级复用，同时也是 React 跨片段协调和增量解析所依赖的路径。incrementalParse 默认 true，但 blockMemo=false 时不生效。服务器完整解析。

独立文档中，优化开关不应改变语义输出；协调文档中关闭 blockMemo 会使跨片段引用保留字面形式，不能把它当作通用性能修复。

## 配置稳定性

组件映射、schema、插件数组与函数应在语义不变时保持稳定。不要原地修改正在使用的值。自定义组件过度重渲染、高亮或布局成本不会被解析缓存自动消除。

## 流式边界

积压的未冻结尾部仍会重复处理。全文预处理器需要访问完整字符串，持续增长的围栏或表格也可能主导耗时。平滑显示还引入自己的调度，不要叠加独立逐字定时器。

先归因，再优化。分别记录解析、转换、React commit、高亮和浏览器布局；历史基准有其特定版本与环境，不代表当前通用收益。见[共享性能概念](rendering-and-performance.md)和[测量指南](benchmarking.md)。
