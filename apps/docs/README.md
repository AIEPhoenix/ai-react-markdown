# AI Markdown documentation workspace

Private Astro Starlight application. See [Documentation site](../../docs/documentation-site.md) for commands, canonical content ownership, link handling and static deployment settings.

From the repository root, run `pnpm dev:docs`. Production output is `apps/docs/dist/`.

An [owner-only preview](https://ai-markdown-docs.aie-eigenlux.chatgpt.site) is available through Sites. This is separate from the project's future public documentation domain.
