# Brand asset

`organization-mark.png` is the ai-markdown GitHub organization's avatar, retrieved from https://avatars.githubusercontent.com/u/312969731?v=4 on 2026-09-11. It is reused unchanged for this project's website. The original brand artwork is maintained at https://github.com/ai-markdown/.github/tree/main/assets.

The website's navy, teal and folded-paper direction is based on the organization's banner and profile. Release status and framework support are sourced from this repository, since the organization profile may lag releases.
